# PTE Reading Practice

这是一个可直接部署到 GitHub Pages 的静态网页项目。

## 上传到 GitHub Pages

1. 在 GitHub 新建仓库，例如 `pte-reading-practice`。
2. 上传本目录中的所有文件和文件夹。
3. 进入仓库的 `Settings` -> `Pages`。
4. `Source` 选择 `Deploy from a branch`。
5. `Branch` 选择 `main`，目录选择 `/root`。
6. 保存后等待 GitHub 生成访问链接。

## 本地数据说明

练习记录、错题记录和我的单词库使用浏览器本地存储保存。别人打开你的 GitHub Pages 链接后，会看到同一套题库和词库，但不会看到你电脑上的个人练习记录。
